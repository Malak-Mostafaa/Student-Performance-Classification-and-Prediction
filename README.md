# 🎓 Student Performance Classification and Prediction
An AI-powered web application designed to predict student academic performance and dropout risk using Machine Learning and Django.

## 📌 Project Overview
This project helps educational institutions identify at-risk students early and provide personalized recommendations to improve academic outcomes.

The system combines Machine Learning with a Django web application to deliver intelligent predictions and actionable insights.

# ✨ Features
- Student performance prediction
- Dropout risk detection
- AI-powered student assistant
- Personalized recommendations
- Student dashboard
- Instructor dashboard
- Prediction history
- PDF report generation
- Email notifications
- Feature importance visualization

# 📊 Dataset

- Previous attempts
